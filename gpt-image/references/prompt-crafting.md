# Prompt 写作指南

## 七层导演法

写 prompt 像导演一场戏。七层不是 checklist，是七个镜头——每层给模型一个锚点。

```
[环境] 背景是什么？空间感？景深？
[主体] 画面中心是什么？数量、位置、关系？
[材质] 表面纹理、反射、透明度？
[光线] 光源方向、色温、阴影类型？
[构图] 视角（俯/仰/平）、留白位置、主体占比？
[色彩] 主色 HEX、辅色 HEX、强调色 HEX、分布比例？
[风格] 媒介（摄影/3D/插画/印刷）、参考艺术家、渲染方式？
```

简单场景（icon / 贴纸 / 表情包）砍到三层：主体 + 色彩 + 风格。

## 反 slop 植入

在对应层直接写负向约束，不要只在外部讨论。

例：在「光线层」写 `"no uniform soft light filling the entire frame, single directional light source only"`

## 一个视觉焦点 120%

不要在所有层都追求极致。选一个层做到极致（通常是主体或光线），其他层自然即可。

例：产品氛围图，主体 120%（材质、反射极致），背景和光线 80%（干净、不抢戏）。
