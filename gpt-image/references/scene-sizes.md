# 场景-尺寸映射

尺寸不是技术参数，是**构图预设**。告诉模型 `"1920x1080"`，它自动理解横向构图、主体偏左、给文字留右边。

## 硬性限制

最长边 ≤ 3840px，总像素 ≤ 830 万。两个约束同时生效。

## 常见场景

| 场景 | 尺寸 | 理由 |
|------|------|------|
| 公众号封面 | `900x383` | 微信 2.35:1 |
| 小红书封面 | `1242x1660` | 3:4 竖版 |
| PPT/视频封面 | `1920x1080` | 16:9 |
| 手机壁纸 | `1179x2556` | iPhone 15 Pro |
| 网页 Banner | `1920x600` | 超宽 |
| Instagram 方形 | `1080x1080` | 1:1 |
| 4K 壁纸 | `3840x2160` | 踩上限 |
| 不确定 | `auto` | 模型推断最佳比例 |

## 合法 vs 非法

```
✅ 1920x1080 = 207 万像素
✅ 3840x2160 = 829 万像素（踩线，合法）
❌ 4000x2250 = 900 万像素（超限）
❌ 3840x3840 = 1475 万像素（最长边合规但总像素超限）
```
